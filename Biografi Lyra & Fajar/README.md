# Biografi Lyra & Fajar

Website biografi pribadi Muhamad Fajar Putra Kiesha dan Lyra Ayu Afura, mahasiswa Teknik Informatika Tanri Abeng University.

Website ini dibuat sebagai media untuk memperkenalkan profil, perjalanan pendidikan, hobi, minat, dan motivasi hidup.

## Isi Website

- Halaman beranda dengan pengenalan Lyra dan Fajar.
- Profil pribadi Fajar dan Lyra.
- Informasi nama, NIM, jurusan, dan status mahasiswa.
- Riwayat pendidikan.
- Hobi dan minat masing-masing.
- Kutipan motivasi hidup.
- Tombol kontak melalui email.
- Navigasi menuju setiap bagian halaman.
- Animasi kemunculan konten saat halaman digulir.
- Tampilan responsif untuk komputer, tablet, dan ponsel.

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript

## Cara Menjalankan

1. Unduh atau clone repository ini.
2. Buka folder project.
3. Buka file `index.html` menggunakan browser.

Website dapat dijalankan langsung karena tidak membutuhkan server atau database.

## Cara Mempublikasikan dengan GitHub Pages

1. Upload `index.html` dan `style.css` ke repository GitHub.
2. Buka menu **Settings** pada repository.
3. Pilih **Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Klik **Save** dan tunggu proses publikasi selesai.

Website dapat diakses melalui alamat:

<https://muhfajarputra-del.github.io/biografi-fajar-dan-Lyra/>

## Catatan

- Pastikan nama file tetap `index.html` dan `style.css`.
- Kedua file tersebut harus berada di folder utama repository.
- Alamat email pada tombol **Kirim Email** masih menggunakan alamat contoh dan dapat diganti di file `index.html`.
